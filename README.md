# ignispyro-public-downloads

Ferramentas independentes de download manual de dados abertos IPMA.

Python 3.11 ou superior, sem dependências externas. Exemplo: `python download.py stations stations.json`. Não substitui ficheiros existentes. Testes: `python -m unittest -v`. As fontes e condições são do [IPMA](https://api.ipma.pt/). Sem tarefas agendadas ou ligação aos NAS.

Versão inicial 1.0.0. Componentes autónomos; não substituem nem modificam o portal IGNISPYRO V2. Sem motores internos ou dados operacionais.
